Open Science Catalog PySTAC extension¶

pystac-ext-osc provides OscExtension for project and product metadata on PySTAC Catalogs, Collections, and Items.

The OSC wrapper targets OSC v1.0.0 and declares https://stac-extensions.github.io/osc/v1.0.0/schema.json. The package version is independent of the specification version.

python -m pip install pystac-ext-osc
